How to Use ChartCraft

                
            

            

                
1. Upload Your Data
Supports CSV and JSON files. Drag and drop or click to browse.

                
2. Describe Your Visualization
Use natural language. Be specific about chart types and columns.

                
3. (Optional) Use AI
Check Use AI in the menu. Choose OpenAI or Gemini. API key optional if set on server.

                
4. Generate
Click Generate. Download the chart or copy/export the code.
